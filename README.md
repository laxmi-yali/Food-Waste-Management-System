# Food-Waste-Management-System
1. Project Description

The Food Waste Management System is a simple Python-based application that helps users manage food donations. Users can add food donations, view available food, calculate the total donated food, and delete donation records.

2. Technologies Used

Python

SQLite Database

3. Features

Add Food Donation

View Food Donations

Calculate Total Donated Food

Delete Food Donation

Store donation details in an SQLite database
